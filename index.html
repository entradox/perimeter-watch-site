Perimeter Watch

Passive external-perimeter monitoring for web agencies. We watch the public metadata around your client domains — cert expiries, takeable subdomains, domain expiries, lookalike domains. Nothing touches your systems. No credentials, no access. We only ask for names.

The four checks

Every run covers the same four checks on every domain you register. Each run produces a one-page brief with evidence.

TLS certificate expiry

Alert when a tracked domain's certificate enters a <14-day expiry window — before a client's site shows an interstitial warning page.

source: Certificate Transparency logs

Dangling DNS / subdomain takeover

Fingerprint every known subdomain for dangling records that point at claimable services — the gap an attacker parks on before you hear about it.

source: can-i-take-over-xyz fingerprints

Domain lifecycle

Registrar expiry monitoring: alert when a client domain enters a <21-day renewal window — the failure nobody notices until the site is gone.

source: public registrar records

Lookalike domains

Watch Certificate Transparency logs for typo and hyphen variants of your domains, flagged only when the variant has live DNS.

source: CT logs · DNS resolution

What this is not

Stated plainly, so nobody is surprised:

  • No port scans
  • No crawling
  • No active testing
  • No takedowns
  • No fixes
  • Not a pentest

Passive public metadata only. We read what is already public. If it requires touching your systems, we don't do it.
